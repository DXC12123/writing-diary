# 小鲸鱼 · 写作日记 v0.9.2

按《个人写作日记 App MVP PRD》做的第一版简单网页实现：**单文件、零依赖、数据存本机浏览器**。

## 打开方式

双击 `index.html` 即可（推荐 Chrome / Edge / Safari）。手机可以把这个文件发到手机浏览器打开，或把整个文件夹拷过去。

## 已实现（对应 PRD 验收标准）

| PRD 项 | 实现 |

| 写日记 | 只写当天，大文本区；输入即自动存草稿（底部显示「已自动保存 hh:mm」），也可点「保存草稿」 |

| 提交锁定 | 二次确认后锁定，输入区只读，页头显示「已锁定 · 提交于 hh:mm」，底部换成「去回顾看看」 |

| 往年的今天 | 回顾日视图与只读详情页底部，列出同一月日往年的条目（年份 · 摘要 · 字数，最多 3 条），点一下进那一天的详情；没有历史时整块不出现 |
| 回顾 · 月 | 12 行列表：「N 月 / 已写 X 天 / N 字」，当前月带陶土圆点，点行进该月日视图 |
| 回顾 · 年 | 年份列表显示「已写 X 天」，点年进入月视图 |
| 只读详情 | 日期、字数、提交时间、正文；底部「上一篇 / 下一篇」按日期相邻翻页 |

| 写作小贴士 | 问题板底部入口 → 目录（基础 4 篇 + 技巧 5 篇）→ 单篇正文；每篇 3 段 + 一句「试着写一句」，底部可翻上一篇 / 下一篇。全部离线静态文本 |

## v0.9.2 改了什么（相对 v0.9.1）

这一版只补「回头看」和「读得舒服」两件事，数据格式没变，老日记照旧：

- **正文字号三档**：设置 → 外观 →「正文字号」小 / 中 / 大。只改写作框和详情正文，页头、Tab、日历一律不动；六套皮肤原本的正文大小差异保留。
- **往年的今天**：回顾日视图与详情页底部，会把同一月日往年写过的条目列出来，点一下直接跳到那一天。
- **详情页上一篇 / 下一篇**：顺着日期翻，比每次回日历点格子快。
- **上次备份**：设置里新增一行只读状态，显示上次导出到第几天、距今多少天；超过 30 天或从没导出过会变成提醒色。它只是提醒，不会替你把文件写到硬盘。
- **首启一句提示**：第一次打开、写作页还空着时，顶部有一句「还没写过。先看一眼这 9 个问题」，写下第一个字就消失。

## v0.9 改了什么（相对 v0.8）

只动问题库，界面和交互没变：

- 问题库从 5199 条扩到 **10194 条**：新增 5 段各 1000 条 —— 家庭与亲密关系、身体与健康、工作钱与社会、内心世界、感官与日常。原来 10 段各 520 条保留。
- 去重规则升级：以前只认「原文一模一样」，现在**忽略空格和标点**再比，避免「同一句、只是问号不同」被算成两条。原始 10200 条 → 去重后 10194 条。
- 抽签方式、浮层、正文保护一字未改；APK 版本号升到 0.9，需要重新出包装机。

## v0.8 改了什么（相对 v0.7）

这一版是「装到手机上之后才看得见的问题」，三件事：

- 名字和图标：应用名改成**小鲸鱼**（标题、关于页、安卓桌面名字都改了），图标换成一头蓝白色小鲸鱼。图标是矢量画的（`android-app/.../drawable/ic_launcher_foreground.xml` 与网页 favicon 用同一份路径），任何尺寸都不糊。
- 状态栏不再是一条白带：页面改成边到边，画到状态栏和导航栏后面，颜色跟着当前皮肤的纸色或壁纸走；深色皮肤（暗黑治愈 / 赛博科技）自动切成浅色状态栏图标。
- 随机问题：写作页点「问题」→ 浮层底部「随机问题」，一次抽 9 条新提示。问题库 5199 条（10 段 × 520 条，加载去重），全部写死在 `index.html` 里，不联网；抽签不重复，浮层原地刷新，正文一个字都不动。（v0.9 已扩到 10194 条，见上一节）

安全区也从写死的 `env(safe-area-inset-*)` 换成了 `--sat` / `--sab` 两个变量：网页版用 env，安卓外壳把原生 insets 写进同名变量，两边共用一套布局。

## 数据在哪

- 日记与偏好：`writing-diary:v1`（localStorage）。`settings.skin` = `paper|cozy|focus|press|cute|tech`，`settings.wallv` = 壁纸浓度 0–100（0 最模糊、100 最清晰，缺省 42）。旧版 `settings.theme`（`light|dark`）只在读取时用于迁移到 `skin`，之后不再写。
- 壁纸：`writing-diary:wallpaper`（单存的压缩后 JPEG data URL，不跟日记混在一起，也不会被「导出 JSON」带出去）。
- 数据结构：`{ questions: [9 个字符串], settings: { skin, wallv }, entries: { "2026-10-21": { content, wordCount, status, createdAt, updatedAt, lockedAt } } }`
- 注意：清理浏览器数据 / 换浏览器 / 无痕模式会丢，**建议定期用「导出 JSON」备份**，换设备后用「从 JSON 导入」搬回来。壁纸不会被导出带走，换设备要重新选一张。

## 这一版刻意没做

账号、云同步、富文本/图片/语音、心情、每日提醒、历史补写、问题板拖动排序、统计图表、搜索 —— 都在 PRD 的「MVP 不包含 / 后续版本」里。

## v0.7 改了什么（相对 v0.6）

这一版做两件事：让备份真的能还原，以及给出一个能装进安卓手机的方式。

- 设置 → 日记多一行「从 JSON 导入」：读文件 → 预览（日记 N 天 / 问题板 N 条 / 与本机重叠 N 天，其中 M 天已锁定）→ 选「合并导入」或「覆盖导入」。
- 合并只补本机还没有内容的日期，已有内容一条都不动；覆盖会清空后换成文件内容。两种都保留文件里的锁定状态，旧日期的草稿仍按跨天规则自动锁定。
- 空正文的草稿条不会导入；坏文件（不是 JSON / 空文件 / 日期非法）只给一条 Toast，不动现有数据。
- 新增 `android-app/`：一个 WebView 外壳（`WebViewAssetLoader` 挂 https 源，避免 `file://` 下 localStorage 清零），**不申请 INTERNET 权限**。
- 新增 `.github/workflows/android.yml`：推到 main 后由 GitHub Actions 出 debug APK，产物在 Actions 的 Artifacts 里。
- 安卓里「导出 txt / JSON」改走系统「保存到」对话框（页面检测到 `window.AndroidHost` 才启用），网页版行为不变。

> APK 的数据和网页版是两份，互不相通；卸载 App 会丢日记。换设备先导出 JSON，再在新设备里导入。详见 `android-app/README.md`。

## v0.6 改了什么（相对 v0.5）

四套风格之后又补了两套，是「场景差得最远」的两个：心情好想写点轻松的时候，和深夜写代码想要一块终端的时候。

- 设置 → 外观的小样从 2×2 变 2×3，多出**超萌可爱**和**赛博科技**。
- 超萌可爱：马卡龙粉 / 蓝 / 黄三段渐变底，格子是气泡卡（24px 圆角 + 粉蓝交替底色 + 同色系柔和投影），主按钮 999px 胶囊，问题格按下有果冻回弹，小贴士入口带一枚 🐾。
- 赛博科技：深空海军蓝底，格子是 1px 青紫霓虹描边 + 内发光，背景铺 24px 科技网格（径向蒙版渐隐），标题 / 标签 / 日期 / Tab 全用等宽字，问题格按下描边闪一次。
- 两套都尊重 `prefers-reduced-motion`：系统开了「减少动态效果」就不做回弹与闪烁。
- 顺手修了一个可读性问题：可爱风的浅粉主色当文字色只有 1.9:1，返回 / 完成 / Tab 选中改用深一号的 `--accent-ink`。
- 数据、结构、操作全部未变，旧选择照旧生效。

## v0.5 改了什么（相对 v0.4）

上一版只有「白天 / 夜间」两档，白天永远是同一张纸。这一版把外观换成 4 套风格，结构、数据、操作一个都没变：

- 设置 → 外观的第一项从「夜间模式」开关换成「界面风格」：2×2 四张小样，点一下即时换肤，Toast 回执「已切换到「…」」。
- 四套皮肤：**日系手账**（默认，暖纸、便签格、胶带、楷体标题）/ **暗黑治愈**（深夜独处，暖光、大圆角、低对比）/ **极简专注**（大留白、毛玻璃、黑白为主）/ **复古打字机**（旧纸、深绿、等宽字、双线框与内框）。
- 小样是用真实 CSS 变量画的迷你界面，不是截图，所以永远和当前皮肤一致。
- 旧选择不会丢：原来开「夜间模式」的人升级后自动落在「暗黑治愈」，其余落在「日系手账」。
- 壁纸和皮肤互不干扰：换皮肤不动已选壁纸，页头 / 页脚的遮罩按皮肤给色，图片上的字仍然看得清。
- 字体全部用系统自带（楷体 / 仿宋 / 等宽），不引外链、不加体积。

## v0.4 改了什么（相对 v0.3）

问题板解决了「写什么」，但卡住的时候还需要「怎么写」，于是补了一条不出 App 的路：

- 问题板底部加「写作小贴士」入口卡，空态和填满都在。
- 点进去是目录：写作基础 4 篇 + 技巧提升 5 篇，编号 01–09 连续。
- 每篇 3 段正文，末尾一个「试着写一句」的提示块，可以直接照着写第一句。
- 正文底部有上一篇 / 下一篇，可以连着读，不用退回目录。
- 内容全部写死在 `index.html` 的 `TIPS` 数组里：不发请求、不占存储、不记阅读进度。

同时把问题板空态从 9 个疏格子改成了 9 行清单，空白少了约 400px。

## v0.3 改了什么（相对 v0.2）

上一版按「一张安静的纸」做到能写完、能回看，但有几处让人卡住或看不懂：

- 锁定之后页面没有出路 → 页脚加「去回顾看看」。
- 提示浮层 9 个格子放不下一屏、也读不成句 → 改成列表。
- 月视图 12 张卡片里 11 张写「已写 0 天」→ 改成列表，只有有记录的月份才亮。
- 回顾日视图下半屏空着 → 加「最近写过」。
- 问题板空态 9 个虚线框吵过顶部的说明块 → 空态退成背景。
- 另外把两处不到 4.5:1 的说明文字调深，切页加了 180ms 淡入。

想退回 v0.2：见 `archive/v0.2-rollback.md`（本机 PowerShell 起不来，没法整份复制备份，改用逐块原文记录）。
